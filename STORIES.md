# User story 1 - Katalog
Som en användare vill jag kunna se alla böcker som finns i en lista
och markera böcker som favoriter

favoritmarkeriong påverkar mina böcker och statistik
    



# User story 2 - Lägg till bok
Som användare vill jag kunna lägga till böcker som saknas i listan och kunna se tillagda böcker i listan

påverkar statistik och katalog





# User story 3 - Mina böcker
Som användare vill jag se de böcker som är favoritmarkerade i en egen lista

    




# User story 4 - Statistik
Som användare vill jag kunna se statistik på de böcker som är favoritmarkerade
